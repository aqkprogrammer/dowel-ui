# Changesets

Every user-facing change needs a changeset. Run `pnpm changeset`, pick the
affected packages and a bump type, and describe the change in one sentence
written for a consumer of the library, not for a reviewer of the diff.

`dowel-monorepo` and `@dowel/config` are private and are ignored here.

See https://github.com/changesets/changesets for the full workflow.
